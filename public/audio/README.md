# Optional audio assets
Place MP3 files here using the exact Sanskrit word as the filename, URL-encoded by the browser when requested.
Example folder: `public/audio/school/` and file `शिक्षकः.mp3`.
If a file is missing, the game falls back to the browser Speech Synthesis API with `sa-IN` when available.
Audio is optional for the MVP, matching the earlier Dialogue Game lesson that reliable, level-aligned audio should not block core gameplay.
